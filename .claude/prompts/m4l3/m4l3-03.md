# M4L3 / Krok 3 — potwierdź twierdzenia strukturalne (`ast-grep`)

Repo: https://github.com/apache/maven (Java)  
Raport: `context/changes/{change-id}/research.md` (domyślnie `model-builder-flow-analysis`)

## Wymagania konieczne

- Śledztwo, nie refaktor — zero `-r` / `--update-all` / rewrite YAML. W tej lekcji `ast-grep` tylko czyta.
- Język wzorców: **Java** (`-l java`), nie Go z lekcji.
- Reguła: precyzja `ast-grep` + każde **zero** potwierdź klasycznym `grep` / `rg` (odróżnij brak wystąpień od złego wzorca).

```text
Ulepszamy raport context/changes/model-builder-flow-analysis/research.md
(w apache/maven, Java — nie Mattermost/Go).

Jeśli nie ma ast-grep: zainstaluj (brew install ast-grep) i sprawdź ast-grep --version.

Najpierw wypisz z raportu wszystkie twierdzenia STRUKTURALNE:
- liczby call-site’ów,
- „tylko tutaj” / „zawsze przez X”,
- liczność metod / override’ów,
- powtarzające się kształty wywołań (np. build(...), DefaultModelBuilder, Session, SPI lookup).

Dla każdego zbuduj wzorzec ast-grep w składni Java, np.:
  ast-grep -p '$X.build($$$A)' -l java
  ast-grep -p 'new DefaultModelBuilder($$$A)' -l java
(dostosuj wzorce do realnych kształtów z raportu — nie kopiuj ślepo przykładów Go z lekcji typu $X.Post().Save).

Wywołaj ast-grep, przeanalizuj wyniki — potwierdź lub obal twierdzenie z raportu.
Używaj ast-grep dla precyzji, ale każde zero potwierdzaj programem grep

Wynik podaj jako: twierdzenie -> potwierdzone / doprecyzowane / obalone, z dokładnymi plikami i liniami.
Każde zero z ast-grep potwierdź klasycznym grepem/rg, żeby odróżnić realny brak wystąpień od złego wzorca (np. inna nazwa metody, typ generyczny, wywołanie przez interfejs).

Uwzględnij pułapki Javy w tym repo:
- wywołania przez interfejs api/* vs klasa impl/*,
- most compat (dwa DefaultModelBuilder — impl vs legacy),
- kod generowany z .mdo (trafienie w generated ≠ ręczne call-site’y),
- refleksja / SPI / ClassRealm — mogą nie być widoczne w AST call-site; oznacz jako unknown, nie „brak wywołań”.

Na koniec zaktualizuj i skoryguj research.md wynikami z ast-grep. Nie zmieniaj kodu źródłowego Mavena.
```
